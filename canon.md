# Canon — who we trust, and why

The library's quality bar is the best independent Google Ads practitioners, not Google's recommendations. This file decides whose view wins. Every dossier starts here.

## 1. Inclusion rule

A source belongs in the canon only if it:

- (a) **publishes its actual method** — the steps, thresholds, scripts or queries it uses, not just takes or predictions;
- (b) **disagrees with Google in public at least sometimes** — a source that has never contradicted a Google recommendation is a relay, not a practitioner;
- (c) **shows evidence** — account data, studies across many accounts, scripts, reproducible analyses or documented results, rather than opinion alone.

Agency blogs written for lead generation, "10 tips" listicles, tool-vendor content that exists to sell the tool, LinkedIn hot takes without a method, and Google's own recommendations fail this rule. A source can pass for one topic and fail for another; dossiers cite per topic.

## 4. Reference only

Google Ads Help, Google Ads developer docs, the Google Ads API changelog, Merchant Center Help, Google Ads Liaison posts. Used solely to state what the platform currently does and when it changed. Never cited as the reason to do something. Every "platform currently does X" line in a dossier is labelled `[Google docs]`.

## 5. Conflict rule

1. Tier 1 beats Tier 2.
2. Evidence beats opinion at any tier. A cross-account study beats a single-account anecdote; a single-account result with numbers beats an unsupported claim.
3. Newer beats older if the platform changed in between. Check the dates against the `Invalidated by` line.
4. When Tier 1 sources disagree with each other, the skill presents both positions and takes one, with the reason, in the "Open disagreements in the canon" section.
5. Google's recommendation is never a tiebreaker.
