# Dossier — 42 Value-based bidding for lead gen (proxy values)

## Sources

1. **Source**: Frederick Vallaeys, Optmyzr — "Value-based bidding guide", https://optmyzr.com/blog/value-based-bidding-guide · **Tier** 1 · **Date** 2026-07-16 · **Claim**: Proxy lead value = close rate × average deal size (10% × $5,000 = $500). Tier leads by source, form completeness or CRM score; a lead converting at 20% is worth ~2× one at 10%. Estimated relative differences beat uniform values. Don't stack values across primary actions in one funnel ($10 + $20 + $50 = $80 counted for one sale) — demote overlapping actions to secondary. Google's 15 conv/30 days (Search) is an eligibility floor, not a reliability threshold; practitioners want 30–50/month; below that use Max Conversion Value without a target to build history. Set initial tROAS from last 30 days' value ÷ spend. Experiments need ~2× the volume, ≥3 conversion cycles or 4 weeks before reading, 4–8 weeks runtime. Learning period 1–2 weeks; conversion lag misattributes; stale CRM values and silent offline-import failures are the common breakages; offline import migrated to Data Manager API from 2026-06-15; GCLID windows 90 days upload / 55 days restate (verify). · **Evidence**: illustrative maths, support-ticket patterns, Google docs; no controlled study.

2. **Source**: Navah Hopkins, Optmyzr — "The Impact of PPC Bidding Strategies", https://www.optmyzr.com/blog/impact-of-ppc-bidding-strategies/ · **Tier** 1 · **Date** 2024-09-24 · **Claim**: In lead-gen accounts, Max Conversion Value is the most used strategy and outperforms Max Conversions by almost 300% on ROAS; Max Clicks and Manual CPC gave some of the cheapest CPCs and strongest ROAS in lead gen. Targets help only on Manual and tROAS; on Max Conversion Value, advertisers without a target did better on most metrics. 50+ conversions/30 days is the threshold for predictable results; 25–50 does not reliably beat <25. · **Evidence**: 14,584-account study, stated weights; ROAS in lead gen is computed on whatever values advertisers loaded, so it partly measures the proxy itself.

3. **Source**: Megan Mullarky, Metric Theory — "Bending the algorithms: using Google's tROAS for customer-acquisition goals", https://metrictheory.com/blog/bending-the-algorithms-using-googles-target-roas-bidding-on-for-customer-acquisition-goals/ · **Tier** added-Tier-2 for this topic (publishes exact method, ratio maths and a YoY account test; contradicts Google's "use real revenue") · **Date** 2021-03-05 · **Claim**: Static "placebo" values on the pixel qualify an account for tROAS. Anchor the final conversion at estimated LTV ($150), value each micro-conversion at LTV ÷ (1 ÷ stage-to-close rate) (20% → $30). Only the ratio between values matters. Set tROAS = placebo revenue ÷ cost (e.g. $870 ÷ $300 = 290%, equivalent to $100 CPA). Keep placebo ROAS above 100% — tROAS behaves better when placebo revenue exceeds spend. Update the tROAS target the moment any value changes. · **Evidence**: one client test, YoY: tCPA CPA +22%, conversions −11% at +37% spend; tROAS CPA −10%, conversions +51% at +37% spend.

4. **Source**: Jarrett Fleagle, WebMechanix, published on Optmyzr — "Value bidding case study", https://optmyzr.com/blog/webmechanix-value-bidding · **Tier** added-Tier-2 for this topic (method + account numbers) · **Date** 2022-08-17 · **Claim**: Rehab/mental-health lead gen: valued each action (call, form, insurance verification) from average downstream revenue via MQL/SQL/closed rates, moved to tROAS on 2021-10-29. · **Evidence**: single account, no control: first ~4.5 months calls +161%, forms +58%, CPL −31.5%; nine months calls +96%, forms +267%, CPL −54%.

5. **Source**: Sarah Stemen, Search Engine Land — "Value-based bidding: why it's key to boosting your Google Ads", https://searchengineland.com/?p=437240 · **Tier** 2 (contributed column; cites Miles McNair and Melissa Mackey) · **Date** 2024 · **Claim**: Two approaches — ranked (ordinal) values, which can't express ROI, or monetary values from LTV × margin × sales knowledge. For budget-constrained accounts, value micro-conversions the sales team says predict bookings. McNair ranks testing VBB through Experiments as his top recommended test. Dissent recorded in comments: Michael De Boeck objects to VBB as the "ultimate upgrade" because value strategies are biased toward higher-value conversions (i.e. they chase whatever you weighted). · **Evidence**: opinion and hypothetical; no data.

6. **Source**: Ginny Marvin (Google Ads Liaison), Search Engine Journal — "Assigning conversion values to make VBB work for lead gen" (2024-09-11) and "Is value-based bidding your ticket to higher quality leads?" (2024-08-28), https://searchenginejournal.com/assigning-conversion-values-to-make-value-based-bidding-work-for-lead-gen/526349 and https://beta.searchenginejournal.com/is-value-based-bidding-your-ticket-to-higher-quality-leads/525205/ · **Tier** Reference only · **Claim**: Proxy values are acceptable if they reflect relative importance; adjust by location/audience/device with conversion value rules; upload daily. Headline stat: advertisers moving tCPA→tROAS see ~14% more conversion value at similar ROAS (Google internal data, March 2021). · **Evidence**: vendor; the 14% measures conversion value (which the advertiser defined), not lead quality.

## Dissenting view
De Boeck (via Stemen/SEL, 2024) and Hopkins' study (2024) between them make the case against: value strategies optimise toward whatever you weighted, so a proxy ladder that is wrong is worse than tCPA; and Max Conversion Value *without* a target beat the targeted version in the cross-account data. The disagreement is about whether tROAS with proxy values is a precision instrument (Mullarky, Fleagle) or a way to encode your own guess into the bidder and then measure yourself against it (De Boeck, Hopkins). Everyone agrees Google's 14% figure doesn't speak to lead quality.

## What the platform currently does [Google docs]
- [Google docs] tROAS eligibility: 15 conversions in 30 days (Search/Display); 20 in 45 days per Merchant Center ID (Shopping) (per Vallaeys 2026).
- [Google docs] Conversion value rules adjust values by location, audience, device; additive when they overlap; apply to Search, Shopping, Display, PMax; same adjusted value appears in reporting (Marvin 2024).
- [Google docs] Offline conversion import moved to the Data Manager API from 2026-06-15; legacy pipelines may fail silently (Vallaeys 2026).
- [Google docs] "Maximize conversion value with a target ROAS" is the current naming; the old 20%/two-week target-change guidance is being phased out as of Aug 2026 (Vallaeys 2026).

## Baseline check
Read `google-ads-bidding` (tROAS section: "50+ conv/mo, meaningful variation in values") and `google-ads-conversion-tracking` (static values). Baseline says to use tROAS only with real values and to fall back to tCPA when values are uniform. This skill adds the opposite play: constructing proxy values from stage-to-close ratios so lead gen *can* use value bidding, the ratio-only principle, the placebo-ROAS target formula, the no-stacking rule, the 30–50 vs 15 threshold argument, and the specific account results and failure patterns.

## Judgment calls
- Mullarky (Metric Theory) and Fleagle (WebMechanix) added as topic-scoped Tier 2: both publish method and account numbers; both contradict Google's "use real revenue" line. Flagged as single-account, uncontrolled.
- Hopkins' lead-gen ROAS finding is treated as evidence that MCV *behaves* differently, not that it makes more money — ROAS on proxy values is circular.
- Took the position: ratio-based ladder anchored at close value, no target for the first 4 weeks, then tROAS from observed value/spend. That reconciles Mullarky's method with Hopkins' no-target finding.
- Post-review: the 3–5 rung limit and the quarterly ratio re-check are Epiminds operating rules with no canon source, labelled as such in the skill; the ~2× group-difference trigger is derived from Vallaeys' 20%-vs-10% example.

## Canon strength: Strong
Two Tier 1 (Vallaeys method; Hopkins cross-account data), two added Tier 2 with account results, one Tier 2 column recording the dissent.

## Invalidated by
Google changing conversion value rules, removing Max Conversion Value without target, changing tROAS eligibility floors, or the Data Manager API changing offline value upload.
