## Dissenting view
Vallaeys (2024) and Hopkins (2026) treat PMax search-term data as a negatives-and-copy source, and Hopkins repeats Google's brand-exclusion guidance. Rhodes and Rooijmans treat the same data as a structural signal (brand share of spend → "close-to-brand" bucket, categories rising → reallocate). The disagreement is whether the brand share in PMax is a hygiene item (exclude it) or the first number that decides whether PMax is earning its budget at all. Rooijmans also notes placement scripts only "suggest" because exclusion is manual; the Rhodes docs frame placements as a report plus the exclusions form.

## Baseline check
Read `google-ads-scripts` (generic script templates, no PMax) and `google-ads-anomaly-detection`. Neither covers PMax: no channel-split reporting, no `campaign_search_term_insight` / `performance_max_placement_view`, no product bucketing, no brand-share reading. This skill names the canonical script, its tabs and thresholds, and the decisions each tab drives.

## Judgment calls
- The row says "Setup / One-off"; the script is scheduled, so the skill treats install as one-off and reading as weekly (Rhodes docs: Campaign tab is the weekly check-in).
- Product-bucket thresholds have no documented defaults; the skill tells the operator to set cost and ROAS thresholds from the account's break-even ROAS and the fixed 10c/day placement threshold is quoted as the only documented default.
- Nils's scripts are treated as the free alternative set; the paid Rhodes script is the canonical tool because the canon names it so.

- Review fix: the feed-only-PMax remedy in step 2 is labelled an Epiminds operating rule (no fetched source on what a feed-only build does to the channel split); the step now escalates to the structure skill.

## Canon strength: Strong
Three Tier 1 practitioners (Rhodes, Rooijmans, Vallaeys/Hopkins) with published scripts and thresholds.

## Invalidated by
Google exposing channel-level spend, cost-bearing search terms and placement cost natively in the PMax UI/API (reported as rolling out 2025 — the script then becomes a convenience, not the only source); deprecation of `campaign_search_term_insight` or `performance_max_placement_view`; Google Ads Scripts API-version sunsets breaking the script's queries.
