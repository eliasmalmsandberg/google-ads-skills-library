# SKILL.md template

Every skill follows this structure. Keep section headings exactly; add nothing before "What this is". Write for a Google Ads practitioner: no definitions of basics, no preamble. Paraphrase sources; don't quote at length. Every claim must be in the dossier and attributed inline as `(Source, year)`.

```
---
name: <slug>
id: <index id>
description: <one line: when to use this; what it is NOT for>
tags: <type> / <campaign type> / <phase> / <maturity> / <cadence>
last_verified: <YYYY-MM-DD>
invalidated_by: <platform changes that would break this>
---
## What this is
## Where it comes from (canon sources, 2–3 lines)
## When to use it / when not to
## Inputs
## Method (the decision rules; numbered)
## What Google will tell you instead, and why we don't
## Failure modes
## What to measure
## Open disagreements in the canon
```

