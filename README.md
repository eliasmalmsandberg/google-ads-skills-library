# Google Ads skills library (Epiminds, internal)

Narrow, opinionated Google Ads skills and SOPs built from the best independent practitioners — the layer above what a model already knows.

## How to work on it
Open this folder in Claude Code and type `/build-library`. It builds or resumes from the index.

## Files
- `google-ads-skills-index.xlsx` — the 90-row backlog and live progress tracker (filter by Status, Phase, Priority)
- `canon.md`, `rubric.md`, `template.md` — created on first run; the quality system
- `skills/<id>-<slug>/` — one folder per skill: `dossier.md` (research), `SKILL.md`, `review.md`
- `changelog.md` — every judgment call, dated
